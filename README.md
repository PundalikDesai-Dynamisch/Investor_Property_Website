# Pune Property Investor: website rebuild

Next.js 16 (App Router) · React 19 · TypeScript (strict) · Tailwind CSS 4 · Radix UI primitives with shadcn-style wrappers · React Hook Form + Zod.

```bash
npm install
npm run dev            # http://localhost:3000
npm run build && npm start
```

Copy `.env.example` to `.env.local`. `LEAD_WEBHOOK_URL` is where enquiries go (CRM, Google Sheet, WhatsApp automation). Without it, leads append to `data/leads.ndjson`, which only works on a writable disk.

## What is built

327 pre-rendered pages from real data crawled from the live site on 1 Oct 2026:

| Area | Route | Notes |
|---|---|---|
| Home | `/` | Search, featured, areas, services, process, insights, developers, videos, reviews |
| Discovery | `/properties/` | URL-based filters (area, budget, BHK, stage, developer, video), sort, search, load more, save, compare (2 to 4) |
| Project pages | `/{slug}/` (188) | Same root URLs as today. Fact sheet, price table, video, floor plans, map, FAQ, contextual lead form |
| Areas | `/2-bhk-flats-in-{area}/` (8), `/locations/{area}/` (6 new), `/locations/` | Legacy hub URLs kept; areas that had no page now have one |
| Developers | `/developers/`, `/developers/{slug}/` | 82, derived from project data |
| Insights | `/blogs/`, `/{slug}/` (8) | Category filter, search, article layout, Article schema |
| Other | `/services/`, `/about-us/`, `/contact-us/`, `/video-gallery-project-tours/`, `/luxury-properties-in-pune/`, `/emi-calculator/`, `/home-loan-eligibility-checker/`, `/compare/`, `/saved/` | Privacy, terms, careers, media, awards render from `data/pages.json` at their old URLs |

Root-level slugs are resolved by `app/[slug]/page.tsx` (project, article, area hub, legacy page). Old short slugs and renamed pages redirect in `next.config.ts`. `trailingSlash: true` keeps every URL identical to the current site.

## Structure

```
app/                 routes, metadata, sitemap.ts, robots.ts, api/leads
components/ui.tsx    button, container, tags, breadcrumbs   dialog.tsx  Dialog / Sheet / Accordion (Radix)
components/property  card, discovery (filters), gallery, map + video facades, detail page
components/lead      lead provider (one dialog, four intents) and form
lib/types.ts         domain models   lib/data.ts  loaders and derived stats   lib/areas.ts  light constants (client-safe)
data/*.json          content generated by scripts/ (properties, posts, videos, pages, hubs)
scripts/             crawl.py, extract.py, properties.py, build_data.py (re-run against a fresh crawl)
                     pick_covers.py swaps soft covers for sharper photos of the same project and lists hero candidates;
                     data/hero.json holds the five hero images (1.6k to 3.8k px wide)
audit/url-inventory.csv   every URL found on the old site with title, canonical, robots, word count
audit/image-sources.csv   every image link the new site uses: page, role, source, size, HTTP status
docs/                     Pune-Property-Investor-Website-Documentation.pdf: how the site was built, data sources, accuracy check
```

Design tokens live in `app/globals.css` (`@theme`). A dark theme overrides them under `html[data-theme="dark"]`; it follows the system setting until a visitor uses the header toggle. Fonts: Newsreader (display) and Manrope (interface) through `next/font`.

## Needs the client before launch

1. **Images are hotlinked** from `punepropertyinvestor.com/wp-content/uploads`. Move them to your own storage or CDN and update `remotePatterns`, or they break when the old site goes away.
2. **Conflicting facts** (shown "as published", flagged in `data/properties.json` under `flags`): 62 projects lack a RERA number, 30 lack a starting price, 56 lack a developer, 9 show different prices in the headline and the configuration table. The old site also states 900,000 and 1,200,000 sq ft sold, and both "2 to 3 years" and "nearly three decades" in business. The new site shows neither.
3. **Litigation "Yes"** appears on 39 projects with no explanation. Add a note per project.
4. **Phone numbers**: 7398174444 (enquiries) and 9970791999 (call and WhatsApp buttons) both exist. Set the primary in `lib/site.ts`.
5. **Stats** (20,000+ clients, 10,000+ site visits, 200+ team) are the old site's figures. Confirm before launch.
6. **Missing everywhere**: amenity lists, nearby places, price per sq ft, payment plans, unit counts, developer logos, area photos, brochures for 138 projects (50 PDFs exist). These need a CMS or admin entry.
7. **Luxury** is defined as a starting price of ₹2 Cr or more (`LUXURY_FROM_LAKH`). Confirm.
8. **Loan rates** in the eligibility checker are the four on the old page. Make them editable.
9. **Analytics**: the old site has no Google Analytics, Tag Manager, Ads or Meta Pixel. Add tracking and a consent banner.
10. **Two project pages** need restoring from WordPress: `goodwill-elements-lohegaon` and `31-palma-drive-upper-kharadi` redirect to each other in a loop.
11. **CMS**: content is JSON for now. `lib/types.ts` is the schema to model in Payload or Sanity.
12. **Retired URLs** (shop, cart, account, login, colour tests, empty pages) return 404. Serve 410 at the edge if you want faster de-indexing.

13. **Image filter**: extraction skipped real images whose file names contain `whatsapp`, `without-logo` or `brochure_page` (about 140, including every floor plan of 10 projects, such as Kumar Magnacity). Fix `BAD_IMG` in `scripts/build_data.py` and re-extract.
14. **Capital-letter URLs** `/2-bhk-flats-in-Dhanori/` and `/2-bhk-flats-in-Charholi/` need a case-sensitive redirect in a proxy (middleware); redirect rules ignore case and would loop. They return 404 on Linux.
15. **Duplicate projects**: Riverdale Grand, Adani Atelier Greens and Mantra 29 Gold Coast each have two pages, so "188 projects" overstates the distinct count (about 182 to 185).

Three of the six reviews come from business partners, not buyers, and are labelled that way.
